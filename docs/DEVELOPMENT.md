# Разработка и сборка

[← К описанию игры](../README.md)

Нативная Java Activity с локальным интерфейсом HTML/CSS/JavaScript в Android WebView. Все ресурсы включены в APK. Разрешение Android `INTERNET` не запрашивается. Имя приложения в списке Android остаётся общим; внутри игры заголовок персональный.

```text
android/AndroidManifest.xml        Версия и настройки Android
android/src/                      WebView и системное меню отправки
android/assets/engine.js           Генерация примеров и награды
android/assets/app.js              Экраны, сохранения и игровой процесс
android/assets/names.js            Имя и склонение
android/assets/petrovich.js        Библиотека склонения (MIT)
android/assets/style.css           Оформление
android/res/                       Значки и тема
licenses/                         Лицензии сторонних компонентов
build.py                          Сборка и подпись APK
test*.cjs                         Проверки логики
```

Для macOS/Linux: Python 3, JDK 17, Android SDK Platform 36 и Build Tools 36.0.0. Укажите свои пути:

```sh
export JAVA_HOME="/path/to/jdk-17"
export ANDROID_SDK_ROOT="/path/to/android-sdk"
python3 build.py
```

Готовый файл — `Mayusha.apk` в корне проекта. При первой самостоятельной сборке создаются личный ключ `mayusha-signing.p12` и файл `signing-password.txt`. Сохраните их для обновлений своей сборки и не публикуйте. Они исключены из Git. Самостоятельная сборка с другим ключом не установится поверх опубликованного APK; для отдельного приложения можно изменить package и путь Java-класса. Закрытый ключ опубликованных выпусков в репозиторий не включён.

Проверки (Node.js 18 или новее, без установки пакетов):

```sh
node test.cjs
node test-names.cjs
node test-profile.cjs
```

Проверяются 27 000 сгенерированных примеров, 54 сочетания настроек раунда, таймер, пауза, повтор ошибок, копилка, миграция старых сохранений, повтор просьбы без списания, склонение имён и смена профиля с сохранением баланса. Отправка в тестах имитируется; реальные сообщения не отправляются. Проверены также сборка и подпись APK, первый ввод имени и изменение имени в браузере. Версию 1.5 и отправку через MAX ещё нужно проверить на физическом телефоне.

При сборке содержимое `licenses/` автоматически включается в APK в `assets/licenses/`. Сохраняйте эти файлы при распространении исходников и приложения.
